# demo-service

A demo Node.js Express website created with Backstage

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
npm install
```

### Running the Application

```bash
npm start
```

The server will start on port 3000 by default. You can change this by setting the `PORT` environment variable.

### Development Mode

```bash
npm run dev
```

This will start the server with nodemon for automatic reloading during development.

## API Endpoints

- `GET /` - Returns service information
- `GET /health` - Health check endpoint

## Documentation

Documentation is available in the `docs/` directory and can be viewed in Backstage TechDocs.
